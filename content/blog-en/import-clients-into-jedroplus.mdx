Start a client import by checking the data rather than uploading the whole file. Jedro+ includes client import from Excel in Free. Confirm available fields and the import method for your file before transferring it. This does not promise automatic transfer of appointments, payments or complete history from every other system.

## 1. Prepare a working copy

Keep the original export separately and edit a copy. Use one person per row. Prepare first name, surname, phone and email where available. This is a review checklist, not a required file schema; agree actual fields before import.

## 2. Check contacts and duplicates

Keep phone numbers as text so the spreadsheet retains leading zeros and + signs. Check email spacing and invalid characters. Family members can share a number, so do not merge records automatically. Your [CRM](/en/features/client-crm) needs a clear record for the right person.

## 3. Test a small sample

Choose different records: both contacts, phone only and a missing value. Check accented characters, field mapping and duplicates. Agree how test records will be corrected or removed with the team before the full import.

## 4. Reconcile the result

Record source rows, accepted records and rows needing corrections. Randomly select five people and compare each contact with the original. The import is complete when you can explain the difference in record counts.

## 5. Enable messages afterwards

Review recipients first and test an [appointment reminder](/en/features/sms-reminders) using your own contact. Check that bookings link to the correct client. The [getting started guide](/en/blog/welcome-to-the-jedro-plus-blog) connects these steps. Email info@jedroplus.com for help with transfer scope and file format.
